Data Import

Import wallet transaction data from TSV format. Duplicate IDs are automatically ignored by the database.

Expected Format

The data should be in TSV (Tab-Separated Values) format with the following columns:

id Amount Reason Type Date

Example:

12345 50.00 Order Payment credit 2024-01-15
12346 -25.00 Supplier Payment debit 2024-01-16
